# ショート予約台帳（メゾン悠遊）

ショートステイの部屋の予約を管理するアプリ。部屋×日付のガントチャートで、空きを探す・重なりに気づく・
予約を動かす、をひと画面でできるようにしたもの。

食事管理アプリとは**別のアプリ・別のスプレッドシート**で動く（統合は後の段階）。

---

## このPCで動かす

デスクトップの「ショート予約台帳（お試し）」をダブルクリック（`start-app.bat`）。
ポートは **3002**（食事管理アプリの3000とぶつからないようにしてある）。

⚠️ すでに3002でサーバーが動いていると再起動できない。コードを直したら先に止めること。

```
npm install
npm run build
npm run start -- -p 3002
```

ログインパスワードは、このPCでは `yoyaku2024`（`RESERVE_PASSWORD` を設定すればそちらが優先）。

## 公開する（Vercel）

### 1. GitHub にリポジトリを作る

`yuyu-shokuji/short-reserve-app`（**Private**）を空で作り、このフォルダから push する。

```
git remote add origin https://github.com/yuyu-shokuji/short-reserve-app.git
git push -u origin master
```

### 2. Vercel にインポートする

[vercel.com](https://vercel.com) → Add New → Project → いま作ったリポジトリを Import。
フレームワークは Next.js が自動で選ばれるので、そのままでよい。

### 3. 環境変数を入れる（Deploy の前に）

| 名前 | 中身 |
| --- | --- |
| `RESERVE_PASSWORD` | ログインパスワード。**必ず設定する**（未設定だとログインを止める） |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | `sheets-migration/service-account-key.json` の中身をまるごと貼る |
| `RESERVE_SPREADSHEET_ID` | 使うスプレッドシートのID（省略時は `lib/sheets.ts` の既定値） |

⚠️ `GOOGLE_SERVICE_ACCOUNT_JSON` は**鍵そのもの**。GitHub には絶対に置かない（`.gitignore` 済み）。

### 4. スプレッドシートの共有を確認する

対象のスプレッドシートが `meal-bot@yuyu-meal.iam.gserviceaccount.com` に
**編集者**で共有されていること。されていないと読み書きできない。

## データ

スプレッドシート「ショート予約台帳」の4シート。**列は見出し名で探している**ので、
列の順番を入れ替えても動く（増やすのも自由。ただし見出し名は変えないこと）。

| シート | 中身 |
| --- | --- |
| `予約` | 予約1件＝1行。ID / 氏名 / 棟 / 部屋 / 開始日 / 終了日 / 状態 / 入所時間 / 入所送迎 / 退所時間 / 退所送迎 / 備考 / 登録日時 |
| `利用者` | 氏名とふりがな（一覧のあいうえお順に使う） |
| `部屋` | 棟・部屋番号・使用しない・仮置き |
| `削除ログ` | 消した予約の退避先。画面からいつでも戻せる |

消した予約は**行ごと消さずに「削除ログ」へ積む**。あとから気づいても戻せる。

## 覚えておくこと

- **食事のルールは `lib/meal-rule.ts` だけに書いてある**（今後変わる前提）。ここを直せば全部追従する
- **重なりの判定は `lib/overlap.ts`**（スプレッドシートに触らない純粋関数）。
  同じ日に交代できるかは**時刻しだい**で決まる（11:00退所→13:00入所はOK、10:00入所はNG）
- **一括で書くときは必ず `batchWrite`**。1件ずつのループはAPIの上限に当たるうえ、とても遅い
- 印刷は**台帳＝A3横1枚／一覧＝A4縦**の2ボタン。**白黒前提**で、確定＝グレーのベタ、仮予約＝斜線

## scripts/

スプレッドシートを直す使い捨てのスクリプト。`node scripts/xxx.mjs` は確認だけ、
`--apply` を付けると実際に書き込む（何度実行しても壊れないように作ってある）。

| ファイル | 何をするか |
| --- | --- |
| `setup-spreadsheet.mjs` | シートと見出しを作り直す（`--id=<ID>`） |
| `inspect.mjs` | いまの中身を見る |
| `fill-default-times.mjs` | 入退所時刻が空の行に既定値（09:00 / 16:00）を入れる |
| `split-soutai.mjs` | 送迎を入所・退所の2列に分ける（2026-09-22に実行済み） |
| `check-names.mjs` | 食事管理アプリ側と氏名の表記がそろっているか調べる（読むだけ） |
| `clone-to.mjs` | 中身を別のスプレッドシートへ丸ごと写す（練習用ファイルを作るとき。`--to=<ID>`） |

⚠️ **サービスアカウントはスプレッドシートを新規作成できない**（Driveの容量を持っていないため）。
新しいファイルが要るときは、人がドライブで作って
`meal-bot@yuyu-meal.iam.gserviceaccount.com` に「編集者」で共有する。
